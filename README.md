# PDF 拆分工具 · 页面预览与 PNG 导出

预览 PDF、选择所需页面，并批量导出 PNG 图片。

[项目主页](https://github.com/fengenxiong-dot/pdf-split-tool) · [作者与项目合集](https://github.com/fengenxiong-dot) · [许可证](LICENSE)

## 为什么做这个工具

培训课件、制度附件和业务材料经常以 PDF 流转，但实际工作中往往只需要其中几页。这个小工具来自日常办公中的文档整理需求，当前重点是把选中的页面导出为图片，便于继续用于课件或其他材料。

## 核心功能

- 使用本地桌面窗口打开 PDF。
- 展示 PDF 页面，辅助选择要处理的内容。
- 点击页面进行多选，状态栏显示已选页数。
- 右键打开导出操作，将选中页面分别保存为 PNG。
- 文件处理在本机完成，不需要接入 AI 模型。

## 适合哪些场景

- 从培训材料中提取需要发给学员的页面。
- 整理制度附件、项目材料和会议资料。
- 将 PDF 页面转为可用于演示或其他文档的图片。

## 第一次使用

### 准备环境

带图形桌面的 Python 3 环境；依赖 PyMuPDF、PyQt5 和 Pillow。

下载方式：会使用 Git 可按下面的命令克隆；也可在本页点击 **Code → Download ZIP**，解压后在项目目录打开终端，跳过 `git clone` 和 `cd` 两步。

### 安装与启动

```sh
git clone https://github.com/fengenxiong-dot/pdf-split-tool.git
cd pdf-split-tool
python -m pip install -r requirements.txt
python pdf_split_tool.py
```

### 操作流程

1. 启动工具后打开一份用于测试的 PDF。
2. 在页面区域查看内容，选择需要处理的页面。
3. 右键点击页面，选择“导出为 PNG”，再选择输出位置。
4. 打开导出文件，核对页数、顺序和图片清晰度。

## 当前状态与限制

当前为源码工具，未提供独立安装包；输出为 PNG 图片，暂不支持将选中页面另存为一份 PDF。加密、损坏或超大 PDF 的处理效果需自行验证；不支持 OCR 文字识别，也不承诺能编辑 PDF 正文。

**验证情况：** 本次完成 Python 语法检查，未进行桌面交互的完整回归。
